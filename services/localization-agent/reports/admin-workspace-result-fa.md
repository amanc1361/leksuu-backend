# تحویل پنل ترجمه — ۲۰۲۶-۱۰-۲۳

پنل روی [leksuu.ir/fa/admin/localization](https://leksuu.ir/fa/admin/localization)
نصب شد؛ مسیر منو «ادمین ← مدیریت ترجمهٔ دوره‌ها» است.

قابلیت‌ها: تنظیم چند سرویس/مدل OpenAI، Gemini و سرویس سازگار؛ نگهداری خصوصی کلید؛
انتخاب زبان، سطح، دوره، چپتر و درس از دیتابیس؛ پوشش متن‌به‌متن؛ ترجمهٔ موارد ناقص؛
صف پایدار با بودجه؛ توقف/ادامه/لغو صف؛ بازتولید یک فیلد؛ ویرایش دستی؛ و انتشار
تک‌بخش یا گروهی پس از بازبینی. تغییر مبدأ و ویرایش هم‌زمان کنترل می‌شوند.

تنظیمات قبلی OpenAI و Gemini بدون نمایش کلید به پنل منتقل شدند. انتخاب مدل
و داشتن API key به معنی داشتن سهمیه و دسترسی inference نیست؛ خطای ارائه‌دهنده
برای هر بخش ذخیره و در پنل نمایش داده می‌شود.

## شواهد

- سرویس داخلی بدون پورت عمومی، با bearer مستقل و نقش محدود PostgreSQL نصب شد.
- API واقعی برای ادمین ۲۰۰ و برای درخواست بدون ورود ۴۰۱ برگرداند؛ تست مسیرهای
  Go دسترسی غیرادمین را رد می‌کند. نقش سرویس حق خواندن کاربران، تغییر answer_key
  یا حذف درس را ندارد.
- ۱۹ دوره از دیتابیس واقعی خوانده شد. چپتر اول A1 شامل ۷ درس و ۵۸ فیلد در هر زبان
  است؛ خواندن شمارنده‌های چپتر تقریباً ۰٫۰۷ ثانیه طول کشید.
- ۱۷ ترجمهٔ منتشرشدهٔ پایلوت قبلی در هر دو زبان تشخیص داده شد؛ پیش‌نویس قدیمی
  سورانی متن اصلاح‌شدهٔ منتشرشده را پنهان نمی‌کند.
- API تنظیمات کلید را برنمی‌گرداند و تنها `has_key` را نشان می‌دهد.
- آزمون مرورگر با API شبیه‌سازی‌شده، انتخاب درس، ترجمهٔ ناقص، ویرایش دستی و انتشار
  تک‌بخش را گذراند. آزمون مرورگر واقعی سایت، انتخاب دوره/چپتر/درس، نمایش ۹ فیلد درس
  اول، بارگذاری دوباره و نمای موبایل را بدون خطای JavaScript یا اسکرول افقی تأیید کرد.
- ۶۵ آزمون Python با PostgreSQL واقعی جداگانه، تمام تست‌های Go، TypeScript،
  lint فایل‌های تغییرکرده و build تولیدی محلی/سرور موفق شدند.
- این نصب و تست روی سرویس AI هیچ inference نفرستاد؛ runs/tasks اصلی تغییر نکردند.
  آزمون‌های نوشتن و انتشار روی دیتابیس تست مستقل اجرا شدند.

### بررسی گزارش نمایش‌ندادن درس اول (۲۰۲۶-۱۰-۲۳)
دو اجرای مدل `gpt-5.6-sol` برای درس `Hello!` از چپتر `Introductions` دورهٔ `English A1 Imported` پیدا شد: هر اجرا ۹ بخش، یکی فارسی و دیگری سورانی. تمام کارهای تولید و بازبینی تمام شده بود و خروجی‌ها به صورت پیش‌نویس ذخیره شده بودند؛ هیچ‌کدام در محتوای دوره منتشر نشده بود. مشکل از شفاف نبودن پایان تولید در برابر انتشار و نبودن نام درس در سابقه بود. سابقه اکنون مسیر دوره/چپتر/درس، زمان، تعداد بخش‌ها و وضعیت انتشار، خطاها و لینک بازبینی همان درس و زبان را نشان می‌دهد. اجرای بدون کار تازه «ردشده» است و محدودهٔ انتخابش را حفظ می‌کند. نام درس اجراهای قدیمی از کارهای ذخیره‌شده بازسازی می‌شود. انتشار همچنان مرحلهٔ جدا و صریحی است.


### حافظه، فهرست خلاصه و انتشار گروهی
حافظهٔ دقیق با کلید زبان/کاربرد/زمینه/نسخهٔ قواعد اضافه شد. درخواست‌های تکراری هم‌زمان یک کار اصلی و پیروهای بدون هزینه دارند؛ خطای نتیجهٔ مشترک درخواست پولی خودکار ایجاد نمی‌کند. پیش‌نمایش تعداد کارهای تازه، قابل استفاده و منتظر را قبل از شروع نشان می‌دهد. فهرست درس‌ها جدول صفحه‌بندی‌شده با فیلتر تکمیل/نقص/انتشار است؛ سابقهٔ هزینه تب جدا دارد. انتشار گروهی نسخهٔ پیش‌نویس را ثبت می‌کند، به مدیر و زمان محدود است و برای هر درس نتیجهٔ روشن و تکرارپذیر می‌دهد. آزمایش‌های محلی از مدل ساختگی و دیتابیس اختصاصی استفاده می‌کنند؛ درخواست inference واقعی برای بررسی لازم نیست.
