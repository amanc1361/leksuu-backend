# گزارش واقعی آزمون و پایلوت — ۲۰۲۶-۱۰-۲۱

## اجراشده

- بررسی SSH سرور، Linux/Docker/PostgreSQL و Caddy مرکزی؛ دیتابیس روی اینترنت منتشر نیست.
- تراکنش‌های READ ONLY برای ساختار پنج جدول آموزشی، شمارش و نمونهٔ واقعی در بررسی اولیه؛ استقرار بعدی فقط schema مستقل را اضافه کرد.
- snapshot کامل درس Affirmative verb forms: ۱۰ آیتم، ۸ تمرین، ۱۷ فیلد مجاز ترجمه و ۴ ابهام نگاشت.
- نمونهٔ واقعی هر ۹ نوع تمرین: fill_blank، fill_gaps، listen_choose، match، mcq، select_words، sentence_builder، speak، true_false.
- `python scripts/test-postgres.py`: **۳۰ آزمون موفق** روی PostgreSQL 17 موقت و MCP SDK واقعی.
- یک هشدار deprecation از Starlette TestClient دربارهٔ httpx گزارش شد؛ تست شکست‌خورده‌ای وجود ندارد.
- migration up/down/up واقعاً اجرا شد؛ نقش محدود واقعاً در PostgreSQL آزمایش شد.
- dry-run و start پیش‌فرض روی DB آزمایشی هیچ run/draft ایجاد نکردند.
- نمونهٔ خروجی dry-run و گزارش HTML سه‌ستونه تولید شد؛ ستون‌های ترجمه به‌صراحت «اجرا نشده» هستند.
- image نهایی Docker ساخته شد؛ smoke test واقعی در حالت non-root/read-only و network=none برای health، رد توکن نامعتبر و فراخوانی MCP get_rules پاس شد.
- Compose config با فایل placeholder موقت معتبر بود؛ فایل‌های secret واقعی خوانده/در خروجی چاپ نشدند.
- پیکربندی پیشنهادی Caddy با image محلی `caddy:2-alpine` و `caddy validate` معتبر بود.

## پوشش آزمون

حفظ پاسخ/گزینه/روابط، هر ۹ نوع تمرین واقعی، placeholder/tag/blank/literal انگلیسی، خط مقصد،
Unicode و bidi مخرب، خروجی کامل و بدون فیلد اضافی، منع تأیید انسانی توسط مدل، idempotency،
transaction کامل، منبع تغییرکرده/answer_key تغییرکرده، حفظ تأیید انسانی قبلی و علامت بازبینی،
refresh بدون enqueue، هم‌زمانی دو worker، pause/lease/reclaim، heartbeat قدیمی، migration rollback،
دسترسی SELECT و منع UPDATE/INSERT/DDL مبدأ و تأیید draft، handshake/auth/body-limit واقعی MCP،
عدم افشای خطای داخلی ابزار، کنترل دسترسی OpenAI بدون inference، نبود fallback محلی، عدم تکرار
create مبهم، بازیابی خروجی همان نشست، ادامهٔ نشست لغوشده با idempotency key و رزرو مشترک بودجه.

تست‌های اتصال OpenAI با HTTP mock هستند و دسترسی یا کیفیت واقعی مدل را اثبات نمی‌کنند.
تست‌های PostgreSQL/MCP با پیاده‌سازی واقعی‌اند. داده‌های «ترجمه» آزمون، sentinel هستند و
خروجی ترجمهٔ واقعی یا نمونهٔ کیفیت فارسی/سورانی محسوب نمی‌شوند.

## هزینه و نتیجهٔ پایلوت

درخواست پولی: صفر. هزینهٔ ایجادشده توسط این کار: صفر دلار API.
کاربر سقف ۵ دلار را تأیید کرده است؛ کلید امن جایگزین هنوز دریافت نشده است.
کلید منتشرشده در چت استفاده یا در فایل/گزارش/log ذخیره نشده و باید در حساب لغو شود.

برآورد تقریبی با tokenizer proxy و allowance ترجمه/بازبینی/reasoning در dry-run.json است:
Sol حدود ۰٫۵۸ دلار، Astra حدود ۲٫۹۰ دلار برای هرکدام یک درس و دو زبان.
تضمین سقف سخت نیست؛ هزینه/زمان/کیفیت واقعی هنوز اندازه‌گیری نشده‌اند.
هیچ ادعای برتری Sorani برای هیچ مدل، یا تأیید بومی ثبت نشده است.

پایلوت واقعی، جدول EN/FA/CKB دارای ترجمه، مقایسهٔ مدل‌ها و پرکردن evaluation-rubric.csv
تا تأیید دسترسی و اجرای مجاز باقی مانده‌اند. ترجمهٔ کل دوره یا انتشار آغاز نشده است.

## باقی‌ماندهٔ وابسته به محیط/تصمیم

۱. لغو کلید افشاشده و اعلام مسیر فایل امن کلید جایگزین با مجوزهای لازم Agents.
۲. SQL پس از درخواست استقرار اعمال و مجوزهای واقعی بررسی شد؛ نصب انجام شده است.
۳. تصمیم دربارهٔ پذیرفتن کنترل هزینهٔ نرم یا الزام سقف سخت سمت ارائه‌دهنده.
۴. استقرار MCP/gateway و HTTPS بیرونی تأیید شد؛ اتصال از خود OpenAI هنوز به کلید جایگزین وابسته است.
۵. پایلوت و ارزیابی انسانی فارسی و سورانی؛ سپس تصمیم مجزا برای اجرای گسترده/انتشار.

initialize، tools/list و دریافت درس واقعی موفق بود. بدون توکن 401 برمی‌گردد.
