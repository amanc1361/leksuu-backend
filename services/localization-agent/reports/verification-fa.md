# گزارش واقعی آزمون و پایلوت — ۲۰۲۶-۱۰-۲۱

> این گزارش وضعیت پایلوت پیش از انتشار است. انتشار بعدیِ مجاز همین درس در [گزارش انتشار](publication-fa.md) ثبت شده است.

**۳۶ آزمون موفق** روی PostgreSQL 17 موقت و MCP SDK واقعی؛ یک هشدار deprecation
از Starlette TestClient دربارهٔ httpx، بدون آزمون شکست‌خورده.
آزمون‌های OpenAI با HTTP mock هستند؛ اجرای پولی واقعی جداگانه نیز کامل شد.

## پوشش آزمون

حفظ پاسخ/گزینه/روابط و ۹ نوع تمرین واقعی؛ placeholder/tag/blank/literal انگلیسی؛
Unicode/bidi و خط مقصد؛ خروجی کامل بدون فیلد اضافه؛ منع تأیید انسانی توسط مدل؛
idempotency، تراکنش کامل، تغییر مبدأ/answer_key، حفظ تأیید قبلی و refresh؛
هم‌زمانی worker، pause/lease/reclaim و heartbeat قدیمی؛ migration up/down/up؛
SELECT محدود و منع نوشتن/DDL مبدأ و تأیید انسانی؛ handshake/auth/body-limit واقعی MCP؛
پنهان‌کردن خطای داخلی ابزار؛ بررسی دسترسی OpenAI بدون inference؛ نبود fallback محلی؛
عدم تکرار create با نتیجهٔ مبهم؛ تشخیص رد قطعی 4xx؛ قرارداد واقعی JSON schema در Agents؛
بازیابی خروجی نشست؛ ادامه با idempotency و بازسازی محدود مرحلهٔ شکست‌خوردهٔ گذرا؛
حفظ تاریخچه/هزینهٔ مدل قبلی؛ race وضعیت failed؛ رزرو مشترک بودجه؛ محاسبهٔ cached input
و fallback به usage turn؛ پذیرش خطای ابزار جبران‌شده و رد خطای جبران‌نشده/درس اشتباه.

## اجرای واقعی

- SSH، Linux/Docker/PostgreSQL و Caddy بررسی شدند؛ PostgreSQL پورت عمومی ندارد.
- migration مستقل پس از ارائهٔ SQL و درخواست استقرار اعمال و نقش محدود واقعاً آزموده شد.
- image non-root/read-only، Compose و Caddy validate موفق بودند؛ image جاری 0.1.5 است.
- HTTPS بیرونی: /fa، /api/v1/courses و /localization/healthz پاسخ 200؛ MCP بدون توکن 401؛
  initialize/tools/list/tools/call با توکن موفق، دریافت ۵ ابزار و ۱۷ فیلد واقعی.
- dry-run اولیه هیچ run/job/draft یا درخواست پولی ایجاد نکرد.
- سپس با دستور صریح کاربر همان کلید فقط در secret کنترل‌گر تنظیم شد؛ دسترسی Agents و
  inference هر دو مدل و خواندن MCP از OpenAI واقعاً موفق شدند.
- پایلوت یک درس completed؛ ۳۴ پیش‌نویس نیازمند بازبینی انسانی؛ مبدأ ثابت؛ انتشار انجام نشده است.

[نتیجه، مسائل کیفیت و مصرف پایلوت](pilot-result-fa.md)؛ مصرف ثبت‌شده تقریباً ۰٫۴۹ دلار،
با usage نامعلوم دو نشست ناموفق، پس هزینهٔ نهایی قطعی نیست.
گزارش سه‌زبانهٔ واقعی در `reports/private/pilot-review.html` است.

## باقی‌مانده

بازبینی بومی سورانی و اصلاح نگرانی معنایی/زبانی، امتیازدهی انسانی rubric و مقایسهٔ
کنترل‌شدهٔ مدل‌ها انجام نشده‌اند. تا تأیید پایلوت، ترجمهٔ کل دوره و انتشار آغاز نمی‌شوند.
صورتحساب/usage کامل نشست‌های ناموفق باید جداگانه تطبیق داده شود.
