# انتشار درس پایلوت — ۲۰۲۶-۱۰-۲۱

با درخواست صریح صاحب پروژه، **همین یک درس** به فارسی و سورانی در اپلیکیشن منتشر شد:
English A1 Imported → بخش پنجم Languages → درس اول Affirmative verb forms.

- [مشاهده به فارسی](https://leksuu.ir/fa/lessons/0625767d-231d-4c45-a340-c389dce5ec2a)
- [مشاهده به سورانی](https://leksuu.ir/ckb/lessons/0625767d-231d-4c45-a340-c389dce5ec2a)

قواعد قبلی ورود و دسترسی دوره حفظ شده‌اند. در صفحهٔ خود درس، عنوان و هدف‌ها ترجمه شده‌اند؛
عنوان اصلی ذخیره‌شده و نام‌های فهرست دوره انگلیسی می‌مانند.

## داده و کیفیت

۳۴ ترجمه منتشر شد: ۱۷ فارسی و ۱۷ سورانی. شش مقدار عنوان/قاعده/معنی در
content_translations با origin=machine ذخیره شد؛ هدف‌ها و عنوان نمایشی به objective و
دستور/توضیح تمرین به نقشه‌های en/fa/ckb در prompt رفتند. مقدار انگلیسی عین مبدأ است.
کد Go، مسیر API و منطق بک‌اند تغییر نکرد. پاسخ‌ها، سؤال‌های نمره‌دار، گزینه‌ها، ترتیب و
payload اصلی آیتم‌ها حفظ شدند. هیچ تغییری برای رایگان‌کردن درس یا شروع کل دوره انجام نشد.

عبارت سورانیِ دارای نگرانی معنایی/زبانی در قاعده، برای نسخهٔ منتشرشده اصلاح شد؛ اصلاح و
متن قبل در رسید خصوصی ثبت‌اند. draft اولیه و مسائل آن پاک یا بازنویسی نشدند.
مجوز انتشار صاحب پروژه ثبت شده؛ **بازبینی بومی تأیید نشده** و draftها human_approved نیستند.
واژه‌نامهٔ تخصصی سورانی هنوز نیازمند بررسی بومی است. انتشار inference جدید یا هزینهٔ OpenAI ندارد.

## آزمون و شواهد

- سرویس مستقل: ۳۹ آزمون موفق PostgreSQL/MCP و نگاشت انتشار، با یک هشدار deprecation.
- TypeScript فرانت‌اند پس از نوسازی فایل‌های تولیدی قدیمی موفق بود.
- ساخت production واقعی Docker/Next.js روی سرور موفق بود؛ فقط frontend راه‌اندازی مجدد شد.
- تست‌های مدل نمایش زبان: ۳ موفق. کل تست‌های فرانت‌اند: ۳۹ موفق و یک شکست قدیمیِ نامرتبط
  در شمارش آرشیو واردکننده (۱۸۸ در برابر ۱۶۴)؛ فایل‌ها و منطق آن تغییر نکرده‌اند.
- lint سه خطای قبلی و شش هشدار در فایل‌های موجود دارد؛ مقایسهٔ خروجی HEAD با تغییر جدید
  نشان داد هیچ diagnostic تازه‌ای اضافه نشده است.
- dry-run انتشار پیش از نوشتن موفق؛ سپس یک تراکنش واقعی committed شد.
- بررسی احراز هویت‌شدهٔ API موجود: ۱۰ آیتم و ۸ تمرین، عنوان/هدف‌ها، گرامر/معنی و توضیح/دستور
  چندزبانه همگی با دادهٔ منتشرشده یکسان بودند؛ answer_key در خروجی عمومی وجود ندارد.
- بررسی بیرونی HTTPS: سایت، API دوره‌ها و لینک مستقیم فارسی/سورانی همگی 200.
- MCP همچنان سالم و بدون توکن 401 است؛ نقش محدود سرویس تغییر نکرد.

رسید ماشینیِ بدون اطلاعات محرمانه: [publication-result.json](publication-result.json).
هش زمینه پس از افزودن ترجمه‌ها تغییر کرده است؛ برای اجرای بعدی snapshot تازه بگیرید.

## بکاپ و بازگشت

مسیر امن سرور: `/root/localization-publication-94d21562`؛ بکاپ کامل دیتابیس با
pg_restore --list بررسی شد. snapshot پیش از تغییر، مقادیر قبلی واژه‌نامه، اصلاح تحریریه و
رسید commit در publication.json با مجوز 0600 موجودند؛ فایل‌ها و image قبلی فرانت‌اند نیز محفوظ‌اند.
credential موقت اپراتور پس از بررسی موفق حذف شد؛ به MCP یا مخزن داده نشد.

بازگشت فقط همین objective/prompt و شش کلید dictionary، پس از کنترل ویرایش‌های بعدی،
طبق [راهنمای انتشار و بازگشت](../docs/publication-fa.md) انجام شود. از restore کل دیتابیس
روی تغییرات بعدی کاربران استفاده نکنید. هیچ schema تازه‌ای برای انتشار ساخته نشد.
