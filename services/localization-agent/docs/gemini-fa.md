# آزمایش Gemini برای چپتر اول A1

در ۲۰۲۶-۱۰-۲۳ از دیتابیس اصلی با نقش فقط‌خواندنی سرویس، چپتر اول
`Introductions` از همان دورهٔ `English A1 Imported` دریافت شد:

- course: `76d38137-3246-432d-b2d1-e5dbc87481b8`
- unit: `9ad02a5c-5971-4f1a-b8eb-c4927fccb363`
- ۷ درس، ۵۸ فیلد برای هر زبان؛ ۱۱۶ ترجمه و ۲۸ درخواست ترجمه/بازبینی برنامه‌ریزی شده.
- سقف تأییدشدهٔ کاربر برای این آزمایش: ۵ دلار.

اجرا از همان `plan`، دستورالعمل `educational-v1`، واژه‌نامه، مدل‌های Pydantic
و `validate` استفاده می‌کند. در این مسیر کنترل‌گر نتایج خواندن context و rules
را مستقیماً به Gemini می‌دهد؛ حلقهٔ OpenAI Agents/MCP در Gemini اجرا نمی‌شود.
هر ترجمه یک درخواست بازبینی جدا با متن انگلیسی دارد؛ این بازبینی ماشینی است.
این ابزار فقط فایل خصوصی پیش‌نویس می‌سازد و در دیتابیس نمی‌نویسد.
برای ذخیره/انتشار بعدی باید هش مبدأ دوباره با دیتابیس زنده بررسی شود.

مدل پیش‌فرض `gemini-4-argon` است. مدل `gemini-2.5-pro` در بررسی GET قابل مشاهده
بود ولی درخواست تولید محتوا با 404 رد شد. نرخ استاندارد Argon طبق
[قیمت رسمی](https://ai.google.dev/gemini-api/docs/pricing) تا پایان نوامبر ۲۰۲۶:
ورودی ۲ و خروجی شامل thinking برابر ۱۰ دلار برای یک میلیون توکن.
برای `gemini-3.8-flash` تا پایان دسامبر نرخ ۰٫۷۵ و ۳٫۷۵ دلار استفاده می‌شود.
پیش از اجرای آینده، نرخ‌ها را دوباره بررسی کنید.
پیاده‌سازی از [generateContent](https://ai.google.dev/api/generate-content)
و خروجی JSON Schema استفاده می‌کند.

## اجرای محلی

کلید افشاشده در چت را لغو کنید. کلید جدید را در ویرایشگر امن، فقط به صورت مقدار
خام و بدون نام متغیر یا نقل‌قول، خارج از مخزن قرار دهید:

```bash
install -d -m 700 /home/amanc/.config/leksuu
touch /home/amanc/.config/leksuu/gemini-api-key
chmod 600 /home/amanc/.config/leksuu/gemini-api-key
nano /home/amanc/.config/leksuu/gemini-api-key
```

از پوشهٔ `services/localization-agent`:

```bash
PYTHONPATH=src .venv/bin/python -m localizer.gemini \
  --contexts reports/private/gemini-chapter1-contexts.json \
  --output reports/private/gemini-chapter1 --budget-usd 5
```

فرمان بالا dry-run است و هیچ درخواست شبکه‌ای ندارد. برای اجرای مصوب، همان
فرمان را با `--execute` اجرا کنید. فایل snapshot در `reports/private` خصوصی و
از Git خارج است و روی محیط دیگری باید از `Store.context` زنده دوباره تهیه شود.
در این محیط تنظیمات عمومی پراکسی ناسازگارند؛ برای اتصال موفق از
`--proxy-url http://127.0.0.1:12334` استفاده شد. اتصال مستقیم ماشین و سرور به
Google با 403 رد شد. این نشانی پراکسی فقط روی ماشین محلی معتبر است.

پیش از هر درخواست، هزینهٔ محافظه‌کارانهٔ ورودی و حداکثر ۸۱۹۲ توکن خروجی/thinking
در `requests/*.json` رزرو می‌شود. این رزروها در همان پوشه زیر قفل مشترک جمع
می‌شوند؛ هزینهٔ تخمینی واقعی نیز از usage ثبت می‌شود. همهٔ ادامه‌ها باید از
همان پوشه استفاده کنند. تغییر پوشه یا حذف ledger بودجهٔ قبلی را منتقل نمی‌کند.
این کنترل تضمین صورتحساب از سوی Google نیست؛ نرخ‌ها و فرض بالای ورودی باید
در اجراهای آینده دوباره بررسی شوند. مدل برای ورودی بلند پذیرفته نمی‌شود.

درخواست timeout، پاسخ نامعلوم، خطای HTTP و پاسخ ناقص خودکار تکرار نمی‌شوند؛
رزروشان باقی می‌ماند. فایل‌های وضعیت را برای تلاش مجدد حذف نکنید.
در صورت توقف به‌خاطر سقف هزینه، اجرای ناقص گزارش می‌شود و سقف خودکار افزایش نمی‌یابد.

پس از تکمیل، `drafts.json` شامل ترجمه‌ها، بازبینی و ایرادهای اعتبارسنجی است و
`review.html` متن انگلیسی، فارسی و سورانی را کنار هم نشان می‌دهد. سورانی همچنان
نیازمند بازبینی بومی است. برای رتبه‌بندی مدل‌ها باید هر دو مدل روی محتوای یکسان
و با بازبینی یکسان سنجیده شوند؛ تفاوت چپتر ۱ و درس قبلی چپتر ۵ برای حکم قطعی کافی نیست.

اجرای ۲۰۲۶-۱۰-۲۳: کلید طبق درخواست صریح مالک در فایل خصوصی خارج از مخزن تنظیم
و دسترسی فهرست مدل‌ها با HTTP 200 تأیید شد. Argon در تولید محتوا خطای
`429 RESOURCE_EXHAUSTED` با سهمیهٔ رایگان صفر داد. درخواست ترجمهٔ Flash timeout
شد و نتیجه/مصرف آن نامعلوم ماند؛ رزرو آن حفظ شد و همان درخواست تکرار نشد.
تا دریافت خروجی کامل، ترجمه‌ای در دیتابیس اصلی اعمال نشده است.

ابزار اپراتور `scripts/publish-gemini-chapter.py` برای دریافت context و drafts کامل
آماده شده است. این ابزار پس از بررسی مجدد هش، تمام ترجمه‌ها را دوباره اعتبارسنجی
می‌کند و تعارض واژه‌نامه را رد می‌کند. حالت پیش‌فرض dry-run است؛ `--execute`
ثبت پیش‌نویس‌ها و انتشار کل چپتر را در یک تراکنش انجام می‌دهد. بکاپ کامل دیتابیس
و رسید خصوصی قبل از commit لازم‌اند؛ ابزار جایگزین بکاپ کامل نیست.
